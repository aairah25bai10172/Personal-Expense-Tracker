# Personal Expense Tracker

A Java-based command-line application for recording, managing, searching, and analyzing personal expenses.

## Objectives

- Record daily expenses
- View all saved expenses
- Search expenses by category
- Delete incorrect expense records
- Calculate total expenses
- Calculate category-wise expenses
- Store expense data permanently in a file

## Features

1. Add Expense
2. View All Expenses
3. Search by Category
4. Delete Expense
5. Show Total Expense
6. Show Category Total
7. File-based data storage
8. Input validation and error handling

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- File Handling
- BufferedReader
- BufferedWriter
- Exception Handling
- Modular Programming
